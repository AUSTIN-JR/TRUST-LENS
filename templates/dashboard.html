📖 About TrustLens

TrustLens is a tamper-detection system for computer vision pipelines using a custom blockchain.

  • Blockchain: Custom Python implementation with SHA-256 hashing
  • Storage: SQLite database for permanent records
  • Verification: File hash comparison against blockchain
  • Security: Tamper detection via cryptographic hashing
